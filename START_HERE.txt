VISIONPLAY - AI ROCK, PAPER, SCISSORS

1. Extract the entire ZIP to a writable folder.
2. Install 64-bit Python 3.11 if needed:
   https://www.python.org/downloads/release/python-3119/
   Choose Windows installer (64-bit), with the Python launcher enabled.
   Python 3.10-3.12 x64 is supported; keep newer Python alongside it.
3. Double-click setup.bat. Internet is required for initial setup.
4. Double-click runme.bat. Click Play or press SPACE.

Fist = ROCK    Open palm = PAPER    V sign = SCISSORS

FIRST TO THREE WINS. Ties do not count.
The computer locks its hidden random move before the 3-second countdown.
Hold your pose steady. An unstable pose gets up to 1.5 extra seconds;
if still invalid, the round is canceled without scoring.
R / New match resets. Q quits.

TRAIN YOUR OWN SVM (optional; pretrained mode works immediately)
G / Guided training opens the step-by-step collector.
Capture / C / SPACE records 40 samples of the displayed pose.
Click Next between rock, paper, scissors, and each of 3 sessions.
Keep the correct pose during capture; reposition between sessions.
Cancel capture or Back / ESC stops collection but keeps saved samples.
T / Train trains the SVM. M switches the game's classifier.
Old 1 / 2 / 3 / N capture keys are no longer used.

E / Teacher view shows the pipeline and your real evaluation results.
Back / ESC returns to the game.
Read TEACHER_GUIDE.md for a one-minute script and README.md for details.
Notepad can open both files.

No webcam photos are saved or uploaded. No administrator access needed.
The earlier version worked on the user's webcam. This upgrade has cloud
checks only so far: test this version on your Windows laptop before class.
